# Portalia · vista previa de la landing

Sitio compilado de la landing de **Portalia** (viernes 4 de diciembre de 2026, Hotel Misión Pachuca) para revisión en GitHub Pages. Es una **vista previa estática**: el programa, los cupos y el acceso premium salen de una copia de los datos con todo «Por confirmar»; no hay registro ni datos de personas.

El sitio real se publicará en `portaliamx.com` con su API. El código fuente vive en repositorios privados de Code Vector; este repositorio solo contiene el resultado compilado, que se regenera con `pnpm build:preview` desde `portalia-web`.

Desarrollado por [Code Vector](https://codevector.com.mx).
